# Name Swap (이름 바꾸기) - SillyTavern 확장

이 채팅에서만 `{{char}}`와 `{{user}}` 이름을 잠깐 다른 이름으로 바꿔서 AI에게 보냅니다. 딱 이 기능만 있어요. 그룹 채팅에서는 멤버마다 따로 바꿀 수 있어요.

## 설치
1. `st-name-swap` 폴더를 `SillyTavern/data/<사용자 폴더>/extensions/`에 넣습니다. (보통 `default-user`)
2. 실리태번을 새로고침(F5)합니다.
3. 확장 패널에서 **Name Swap**이 보이면 성공이에요.

## 사용법
1. 바꾸고 싶은 채팅을 엽니다.
2. 확장 패널의 Name Swap을 열면 맨 위에 **현재 누구로 되어 있는지**가 보입니다.
3. char / user 칸에 이름을 입력하고(그룹 채팅이면 멤버별 칸과 user 칸) **적용**을 누릅니다. 이 채팅에만 적용되고, 다시 열어도 유지돼요.
4. 자주 쓰는 이름은 아래 **저장된 이름**에 저장해 두고, "char 칸에 넣기 / user 칸에 넣기"로 골라 쓸 수 있어요.
5. **원래 이름으로**를 누르면 해제됩니다.

## 알아둘 점
- AI에게 보내는 프롬프트에서만 바뀝니다. 화면의 글과 캐릭터 카드는 그대로예요.
- 영어 이름은 단어 단위로만 바뀌어요. (Sun → Sunny라도 Sunday는 그대로)
- 한글 이름은 조사가 붙어도 바뀝니다. (앨리스는, 앨리스가)
- 그룹 채팅을 열면 char 칸 대신 **멤버마다 칸**이 나와요. 바꿀 멤버만 채우면 됩니다.
- 저장된 이름의 "멤버 칸에 넣기"는 마지막으로 누른 멤버 칸에 들어가요.
- 추가 API 호출은 없습니다.
